# Swift Async Kit

Kit avançado de rede e concorrência em **Swift**.

> English: [README.md](README.md)

## Recursos

- Cliente async com **retry** e backoff
- **Timeout** configurável
- **Cache** em memória com TTL
- Erros tipados e localizados
- Helper de timeout para qualquer operação async

## Instalação

```swift
.package(url: "https://github.com/RknDEV1/swift-async-kit.git", branch: "main")
```
